# Netflix Data Analysis Using Python

## Project Overview
This project explores the Netflix dataset to understand the distribution and characteristics of movies and TV shows available on Netflix.

## Objectives
- Analyze Movies and TV Shows.
- Explore content added over the years.
- Study movie duration and release-year distribution.
- Identify countries contributing the most titles.
- Analyze content ratings and genres.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis and Visualizations
The project includes:
- Pie chart: Movies vs TV Shows
- Line plot: Content added by year
- Histogram: Movie duration distribution
- Bar plot: Top 10 countries
- Countplot: Content by rating
- Histogram: Release-year distribution
- Boxplot: Release-year distribution by content type
- Bar plot: Top 10 genres

## Key Learnings
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn
- Extracting insights from a dataset

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open `netflix_analysis.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells.
